# Circulation Builder for Bombay High Court

[English](README.md) · [मराठी](README.mr.md) · **हिन्दी**

बॉम्बे उच्च न्यायालय के लिए सर्कुलेशन स्लिप अपने ही कंप्यूटर पर तैयार कीजिए, लाइव पूर्वावलोकन में जाँचिए
और एक A4 पृष्ठ पर छापिए।

> **स्वतंत्र साधन।** Circulation Builder बॉम्बे उच्च न्यायालय का आधिकारिक एप्लिकेशन नहीं है।
> इसका उच्च न्यायालय, उसकी रजिस्ट्री या किसी अधिवक्ता संघ से कोई संबंध नहीं है और न ही इसे उनकी मान्यता प्राप्त है।
> यह साधन सर्कुलेशन का अनुरोध तैयार करता है। यह मामला दायर नहीं करता, न्यायालय में स्थिति नहीं जाँचता,
> पंजीकरण की पुष्टि नहीं करता और मामले के सूचीबद्ध होने की गारंटी नहीं देता।

## यह क्या करता है

- आपकी भरी हुई जानकारी से स्लिप बनाता है: मामला संख्या, सर्कुलेशन की श्रेणी, पक्षकारों के नाम,
  सूचीबद्ध करने के लिए माँगी गई तारीख, संक्षिप्त सारांश, अधिवक्ता का नाम और स्लिप की तारीख।
- मामला संख्या के तीन प्रकार चलते हैं: पंजीकृत मामला, स्टाम्प/लॉजिंग संख्या और ई-फाइलिंग संख्या।
- मामले के प्रकार, संख्या और वर्ष से मामला संख्या सुझाता है; आप उसे सुधार सकते हैं।
  छापने से पहले छपने वाली संख्या का अपने मामले के अभिलेख से मिलान आपको ही करना है।
- न्यायालयीन मामले का प्रकार और सर्कुलेशन की श्रेणी, ये दो अलग विकल्प रखता है। मामले का प्रकार
  ३५३ प्रकारों की खोजने योग्य सूची से चुनना है। श्रेणी २६ में से एक है: प्रारूप पर छपी २५ और
  Criminal Matters।
- स्लिप के ऊपरी दाएँ कोने पर **FRESH MATTER** का निशान लगाया जा सकता है।
- आपके शब्द ज्यों के त्यों छापता है। सारांश न स्वयं लिखता है, न छोटा करता है, न बदलता है।
- सारांश या पूरी स्लिप एक A4 पृष्ठ में न समाए तो छापने नहीं देता।

## दायरा

यह संस्करण नागपुर खंडपीठ की सर्कुलेशन स्लिप के प्रारूप के अनुसार है। अन्य खंडपीठ अभी शामिल नहीं हैं।

मामलों के प्रकारों की सूची बॉम्बे उच्च न्यायालय की आधिकारिक वेबसाइट की प्रकार-चयन सूची की स्थानीय प्रति है;
इसे ५ अक्टूबर २०२६ को जाँचा गया है। यह न्यायालय से सीधे ली गई चालू जानकारी नहीं है।

## Mac पर स्थापित करना

डेस्कटॉप एप्लिकेशन Apple silicon वाले, macOS 13 या उसके बाद का संस्करण चलाने वाले Mac के लिए है।

1. [नवीनतम रिलीज़](https://github.com/Wolfgangrush/circulation-builder/releases/latest) से
   `Circulation-Builder-0.1.0-arm64.dmg` डाउनलोड कीजिए।
2. उसे खोलिए और **Circulation Builder** को **Applications** में खींचिए।
3. Applications से उसे खोलिए।

एप्लिकेशन पर Apple Developer ID के हस्ताक्षर हैं और Apple ने उसे नोटराइज़ किया है; इसलिए वह
सुरक्षा-चेतावनी के बिना खुलता है।

पूरी नीति [PRIVACY.md](PRIVACY.md) में (अंग्रेज़ी में) और एप्लिकेशन में **Privacy policy** के अंतर्गत है।

## सोर्स कोड से चलाना

Node.js 22.12 या उसके बाद का संस्करण चाहिए।

```bash
npm install
npm run dev            # ब्राउज़र में फ़ॉर्म
npm run desktop:open   # डेस्कटॉप एप्लिकेशन
```

## परीक्षण

```bash
npm test               # यूनिट परीक्षण
npm run test:e2e       # ब्राउज़र परीक्षण, डेस्कटॉप और फ़ोन आकार
npm run test:desktop   # वास्तविक डेस्कटॉप एप्लिकेशन शुरू करता है
npm run build          # टाइप जाँच और प्रोडक्शन बिल्ड
```

परीक्षणों के सभी उदाहरण काल्पनिक हैं। कृपया इसे ऐसा ही रखिए: किसी वास्तविक मामले, पक्षकार या मुवक्किल की
जानकारी परीक्षण में, issue में या pull request में कभी मत डालिए।

## Mac एप्लिकेशन बनाना

अपने उपयोग के लिए बिना हस्ताक्षर की बिल्ड:

```bash
npm run package:mac
```

हस्ताक्षरित और नोटराइज़ की गई बिल्ड के लिए आपका अपना Apple Developer ID प्रमाणपत्र और
`notarytool` का keychain profile चाहिए:

```bash
CB_SIGN_IDENTITY="Developer ID Application: Your Name (TEAMID)" \
CB_NOTARY_PROFILE="your-notary-profile" \
npm run release:mac
```

रिलीज़ स्क्रिप्ट हस्ताक्षर करने से पहले प्रोजेक्ट की प्रति एक अस्थायी फ़ोल्डर में ले जाती है, क्योंकि iCloud Drive या
OneDrive से सिंक होने वाले फ़ोल्डर में रखे एप्लिकेशन पर macOS हस्ताक्षर नहीं करता।

`build/icon.svg` से आइकन दोबारा बनाने के लिए:

```bash
npm run icons
```

## स्लिप पर भरोसा करने से पहले

- छपी हुई मामला संख्या का अपने मामले के अभिलेख से मिलान कीजिए।
- रजिस्ट्री की वर्तमान कार्यप्रणाली जाँचिए। प्रारूप और समय-सीमाएँ बदलती रहती हैं।
- ई-फाइलिंग संख्या पंजीकरण, स्वीकृति, अनुमति या सूचीबद्ध होने का प्रमाण नहीं है।
- हस्ताक्षर करने से पहले स्लिप पढ़िए। उसके लेखक आप हैं।
