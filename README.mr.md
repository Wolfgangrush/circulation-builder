# Circulation Builder for Bombay High Court

[English](README.md) · **मराठी** · [हिन्दी](README.hi.md)

मुंबई उच्च न्यायालयासाठी सर्क्युलेशन स्लिप तुमच्या स्वतःच्या संगणकावर तयार करा, थेट पूर्वदृश्यात तपासा
आणि एका A4 पानावर छापा.

> **स्वतंत्र साधन.** Circulation Builder हे मुंबई उच्च न्यायालयाचे अधिकृत ॲप्लिकेशन नाही.
> उच्च न्यायालय, त्याची रजिस्ट्री किंवा कोणत्याही वकील संघाशी याचा संबंध नाही आणि त्यांची याला मान्यता नाही.
> हे साधन सर्क्युलेशनची विनंती तयार करते. ते प्रकरण दाखल करत नाही, न्यायालयातील स्थिती तपासत नाही,
> नोंदणीची खात्री देत नाही आणि प्रकरण बोर्डावर लागेल याची हमी देत नाही.

## हे काय करते

- तुम्ही भरलेल्या माहितीतून स्लिप तयार करते: प्रकरण क्रमांक, सर्क्युलेशनचा प्रवर्ग, पक्षकारांची नावे,
  प्रकरण लावण्यासाठी मागितलेली तारीख, संक्षिप्त सारांश, वकिलाचे नाव आणि स्लिपची तारीख.
- प्रकरण क्रमांकाचे तीन प्रकार चालतात: नोंदणीकृत प्रकरण, स्टॅम्प/लॉजिंग क्रमांक आणि ई-फायलिंग क्रमांक.
- प्रकरणाचा प्रकार, क्रमांक आणि वर्ष यांवरून प्रकरण क्रमांक सुचवते; तो तुम्ही दुरुस्त करू शकता.
  छापण्यापूर्वी छापला जाणारा क्रमांक तुमच्या स्वतःच्या प्रकरणाच्या नोंदीशी तुम्हीच पडताळायचा आहे.
- न्यायालयीन प्रकरणाचा प्रकार आणि सर्क्युलेशनचा प्रवर्ग हे दोन वेगळे पर्याय ठेवते. प्रकरणाचा प्रकार
  ३५३ प्रकारांच्या शोधता येणाऱ्या यादीतून निवडायचा. प्रवर्ग २६ पैकी एक: नमुन्यावर छापलेले २५ आणि
  Criminal Matters.
- स्लिपच्या वरच्या उजव्या कोपऱ्यात **FRESH MATTER** अशी खूण करता येते.
- तुमचे शब्द जसेच्या तसे छापते. सारांश स्वतः लिहीत नाही, लहान करत नाही आणि बदलत नाही.
- सारांश किंवा संपूर्ण स्लिप एका A4 पानात बसत नसेल तर छापू देत नाही.

## व्याप्ती

ही आवृत्ती नागपूर खंडपीठाच्या सर्क्युलेशन स्लिपच्या नमुन्यानुसार आहे. इतर खंडपीठे अद्याप समाविष्ट नाहीत.

प्रकरणांच्या प्रकारांची यादी ही मुंबई उच्च न्यायालयाच्या अधिकृत संकेतस्थळावरील प्रकार-निवड यादीची
स्थानिक प्रत आहे; ती ५ ऑक्टोबर २०२६ रोजी तपासली आहे. ती न्यायालयाकडून थेट घेतलेली चालू माहिती नाही.

## Mac वर बसवणे

डेस्कटॉप ॲप्लिकेशन Apple silicon असलेल्या, macOS 13 किंवा त्यापुढील आवृत्ती चालवणाऱ्या Mac साठी आहे.

1. [नवीनतम रिलीज](https://github.com/Wolfgangrush/circulation-builder/releases/latest) मधून
   `Circulation-Builder-0.1.0-arm64.dmg` डाउनलोड करा.
2. ती उघडा आणि **Circulation Builder** हे **Applications** मध्ये ओढा.
3. Applications मधून ते उघडा.

ॲप्लिकेशनवर Apple Developer ID ची स्वाक्षरी आहे आणि Apple ने ते नोटराइझ केले आहे; त्यामुळे ते
सुरक्षा-इशाऱ्याशिवाय उघडते.

तुम्ही टाइप केलेले काहीही कुठेही साठवले जात नाही आणि कुठेही पाठवले जात नाही. खाते नाही, ॲनालिटिक्स नाही,
टेलिमेट्री नाही; आणि डेस्कटॉप ॲप्लिकेशन स्वतःच्या खिडकीतून होणारी प्रत्येक नेटवर्क विनंती नाकारते.
संपूर्ण धोरण [PRIVACY.md](PRIVACY.md) मध्ये (इंग्रजीत) आणि ॲप्लिकेशनमध्ये **Privacy policy** खाली आहे.

## सोर्स कोडमधून चालवणे

Node.js 22.12 किंवा त्यापुढील आवृत्ती लागते.

```bash
npm install
npm run dev            # ब्राउझरमध्ये फॉर्म
npm run desktop:open   # डेस्कटॉप ॲप्लिकेशन
```

## चाचण्या

```bash
npm test               # युनिट चाचण्या
npm run test:e2e       # ब्राउझर चाचण्या, डेस्कटॉप आणि फोन आकार
npm run test:desktop   # प्रत्यक्ष डेस्कटॉप ॲप्लिकेशन सुरू करते
npm run build          # टाइप तपासणी आणि प्रॉडक्शन बिल्ड
```

चाचण्यांमधील सर्व उदाहरणे काल्पनिक आहेत. कृपया ते तसेच ठेवा: खरे प्रकरण, पक्षकार किंवा अशील यांची
माहिती चाचणीत, issue मध्ये किंवा pull request मध्ये कधीही टाकू नका.

## Mac ॲप्लिकेशन तयार करणे

स्वतःच्या वापरासाठी स्वाक्षरी नसलेली बिल्ड:

```bash
npm run package:mac
```

स्वाक्षरी केलेल्या आणि नोटराइझ केलेल्या बिल्डसाठी तुमचे स्वतःचे Apple Developer ID प्रमाणपत्र आणि
`notarytool` चे keychain profile लागते:

```bash
CB_SIGN_IDENTITY="Developer ID Application: Your Name (TEAMID)" \
CB_NOTARY_PROFILE="your-notary-profile" \
npm run release:mac
```

रिलीज स्क्रिप्ट स्वाक्षरी करण्यापूर्वी प्रकल्पाची प्रत तात्पुरत्या फोल्डरमध्ये नेते, कारण iCloud Drive किंवा
OneDrive शी सिंक होणाऱ्या फोल्डरमधील ॲप्लिकेशनवर macOS स्वाक्षरी करत नाही.

`build/icon.svg` मधून आयकॉन पुन्हा तयार करण्यासाठी:

```bash
npm run icons
```

## स्लिपवर अवलंबून राहण्यापूर्वी

- छापलेला प्रकरण क्रमांक तुमच्या प्रकरणाच्या नोंदीशी पडताळा.
- रजिस्ट्रीची सध्याची पद्धत तपासा. नमुने आणि वेळेच्या मर्यादा बदलतात.
- ई-फायलिंग क्रमांक हा नोंदणी, स्वीकृती, परवानगी किंवा प्रकरण बोर्डावर लागल्याचा पुरावा नाही.
- सही करण्यापूर्वी स्लिप वाचा. तिचे लेखक तुम्ही आहात.
